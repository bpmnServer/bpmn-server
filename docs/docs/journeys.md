# Choose your journey

BPMN Server can be tried in a browser, run as your own workflow application, connected to an application you already have, or built into your own code. Pick the one that matches what you want to do. Each journey is a short list of steps, each linking to where it is explained.

| Journey | You want to | Start here |
|---|---|---|
| **A. Online demo** | See what it does, without installing anything | [Online demo](first-workflow.md) |
| **B. Build an application** | Run your own workflow application, with its models, users and services | [Build an application](build.md) |
| **C. Integrate an existing application** | Add workflows to an application you already have, from its own UI and users | [Integrate an existing application](integrate.md) |
| **D. Embed the engine** | Run processes from your own Node.js code, with no web application | [Embedding the engine](embedding.md) |

Not sure? Start with **A**, then **B**: the [tutorials](tutorial/start.md) follow journey B with one example, a leave request, from installing to testing it automatically.
