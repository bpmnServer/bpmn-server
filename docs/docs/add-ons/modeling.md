# Modeling tools (add-on)

The **Modeling tools** add-on gives the model editor its Test and History tabs. Turn it on or off in its card on the
[Settings page](../integration-settings.md) (**Dashboard ▸ Settings ▸ Modeling tools**).

## What it does

- **Test**: a model's Gherkin scenarios, run in the engine from the editor ([testing models](../testing.md)).
- **History**: each save of a model kept as a version, to compare and restore.

## Its settings

| Setting | |
|---|---|
| `MODEL_HISTORY` | Saved versions of models kept (designers change it too) |

## When it is off

The editor has neither tab, and a save keeps no version.
